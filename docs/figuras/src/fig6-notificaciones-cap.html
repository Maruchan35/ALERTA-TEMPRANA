Texto real generado con el código del servidor (supabase/functions/_compartido). Datos de ejemplo, no son personas reales.

Notificación en el teléfono

ALERTA CERCA · ahora
ROBO DE VEHÍCULO
Verificada · Robo de vehículo: Nissan Versa gris

Llega como notificación push aunque la app esté cerrada. El sonido depende del nivel de peligro (canales del 1 al 4).

Verificación por WhatsApp

ALERTA CERCA: tu código de verificación es 482913. No lo compartas con nadie.
21:41

Es el texto que se envía al verificar el número (009_whatsapp.sql). El envío puede ser simulado, por el puente de WhatsApp o por la API oficial de WhatsApp Business (Meta), según la configuración del servidor. El código de la imagen es de ejemplo.

Alerta CAP 1.2 (formato de alertas oficiales)

<alert xmlns="urn:oasis:names:tc:emergency:cap:1.2">
  <identifier>alertacerca-6f1c2b7e-3a9d-4e51-9b0a-2d8e7f4c1a55</identifier>
  <sender>alertacerca</sender>
  <sent>2026-10-08T21:40:00+00:00</sent>
  <status>Actual</status>
  <msgType>Alert</msgType>
  <scope>Public</scope>
  <info>
    <language>es-MX</language>
    <category>Security</category>
    <event>Robo de vehículo</event>
    <urgency>Immediate</urgency>
    <severity>Severe</severity>
    <certainty>Observed</certainty>
    <expires>2026-10-09T03:40:00+00:00</expires>
    <senderName>ALERTA CERCA · CCE Lázaro Cárdenas</senderName>
    <headline>Robo de vehículo: Nissan Versa gris</headline>
    <instruction>No te acerques. Llama al 911 y anota placas y dirección.</instruction>
    <area>
      <areaDesc>Radio de 3.0 km alrededor del suceso</areaDesc>
      <circle>17.9581,-102.1942 3.0</circle>
    </area>
  </info>
</alert>

Fragmento abreviado. Es el estándar OASIS CAP 1.2, el formato con el que las autoridades retransmiten alertas. Lo genera el servidor en cada alerta verificada.
